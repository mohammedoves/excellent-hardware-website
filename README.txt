FREE GITHUB PAGES PUBLISHING
1. Go to https://github.com/ and create/sign in to a free account.
2. Click the + icon (top right) > New repository.
3. Repository name: excellent-hardware-website
4. Select Public. Do not add a README/license/gitignore (the supplied files already include instructions).
5. Click Create repository.
6. Click Add file > Upload files.
7. Upload index.html, style.css and script.js (README.txt is optional).
8. Click Commit changes.
9. Open Settings > Pages.
10. Under Build and deployment, choose Deploy from a branch.
11. Select Branch: main and Folder: / (root), then Save.
12. Wait a few minutes. GitHub Pages will show the published address, usually:
    https://YOUR-GITHUB-USERNAME.github.io/excellent-hardware-website/
